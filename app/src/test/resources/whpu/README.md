# WHPU 脱敏课表回归样本

`schedule-2026-first-redacted.json` 来自 2026-11-08 经用户授权、在学校已登录浏览器中读取的课表响应，包含 27 条 `kbList` 排课和 3 条 `sjkList` 实践安排。

本次样本读取使用课表端点的 GET 查询，参数为 `gnmkdm=N2151`、`xnm=2026`、`xqm=3`、`kzlx=ck`，其余三个筛选参数为空。响应与学校课表页的条目和节周表达式核对一致。样本采集本身仅验证 GET 响应；应用使用原 POST 协议，本地 HTTP 回归覆盖 POST 表单和本样本解析，后续设备上的真实 POST 导入也已由用户确认成功，详见 `docs/whpu-p1.6-evidence.md`。

## 脱敏范围

- 在内存中按白名单提取字段，未将完整原始响应保存到项目。
- 删除 `xsxx`、学生姓名、学号、专业、班级、查询时间、选课时间、内部人员及场地 ID、查询和用户元数据。
- 课程名及课程号替换为“课程N”，教师替换为“教师N”，地点替换为“教室N”，教学班 ID 替换为“教学班N”；同一对象的关联保持一致。
- 实践名称替换为“实践安排N”，多教师列表保留人数及关联。
- 保留学校公共校区名、字段类型、原始节次和周次表达式、教学类型及调课标记。
- 本次选取的字段中没有 null。没有为样本补造 null、缺失字段或原响应未出现的数据；额外边界用例由人工测试单独构造。
- 不包含密码、Cookie、票据或 Token。

## 已验证语义

- 常规课程使用 `zcd`，实践安排使用 `qsjsz`，实践教师使用 `jsxm`。
- `sjkList` 同时包含实习与课程设计；不能按是否有 `sfsjk=1` 过滤该列表。
- `jcs` 对应页面实际节次；实验课可出现 `jcs=5-6`、`jcor=5-8`，也可出现 `jcs=7-8`、`jcor=5-8`。
- `xsdm=02` 对应字典中的实验；即便个别实验行的 `skfsmc=面授讲课`，仍应按 `xsdm` 识别。
- 混合周次的单双周限制只作用于其所在段落。
- 同一课程号的不同教师、地点和周段均保留在排课中。

样本只用于测试，不打包进主应用，不作为用户真实课表或演示课表。
