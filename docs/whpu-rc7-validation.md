# rc7 候选版准备与验收

版本 `0.34.0-rc7`，`versionCode=106`；基线为 PR #23 合入后的 main `244dbe6`。沿用正式签名、Room v10 和现有工具链。当前为发布准备，尚未发布；最终包须在本 PR 合并后从主线重新构建。

## 变更

校园卡和电费内置页在初始化时使用统一的 Android Mobile 浏览器标识，避免学校把电费导航到不可用的 PC 页面。保留实际设备及 Chromium 版本，平板补齐 Mobile 标识，不在登录跳转中途修改标识。

PR #23 的实机结果与接口边界见[电费核验记录](whpu-electricity-evidence.md)：三个分组表单可达，校园卡与独立电费入口通过，校园卡交接及原生刷新回归通过。用户授权房间的照明和空调金额随后经官方页面核验；本版仍仅提供电费网页入口，没有原生电费缓存或组件金额。

## 本候选包验证

- 准备提交 `520d097` 上重新执行全部 548 项单元测试，失败、错误和跳过均为 0；R8 正式 Release 构建与发布检查通过。构建限制两个工作线程，模拟器在构建时暂停。
- APK 版本代码 106、名称 0.34.0-rc7，正式证书与已发布 rc6 一致，未启用 debuggable；APK 内源码提交与准备提交一致。
- 专用 API 31 人工数据模拟器从已安装的正式 rc6 直接 `install -r` 覆盖至 rc7 准备包，没有卸载。升级前后全部数据库表记录一致，DataStore 文件集合和字节一致；非空学习记录与标签、25 分钟统计、校园卡人工余额、免打扰状态页可读。
- 验证后暂停模拟器。以上为准备包结果，不能替代合并后的最终主线构建及发布产物核验。

实体平板保留已验证的 Debug 修复版和原有数据，不为正式签名验证卸载。没有修改或关闭学校登录页面，不触发缴费、绑定、预约或续借。
