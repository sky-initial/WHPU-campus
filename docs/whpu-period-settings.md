# 自定义上课作息与周次强调

日期：2026-11-09。

## 使用方式

在“课表 → 课程表设置 → 上课作息（本学期）”调整当前启用学校学期的第 1—11 节。点击开始或结束时间后，用时、分滚轮选择；采用北京时间、24 小时制。每节课的时长可独立设置。

编辑内容在点击“保存作息”后生效；直接返回不保存。恢复默认也先回填编辑区，再由用户保存。保存前检查完整节数、合法时钟、结束晚于开始，以及相邻节次不重叠，具体错误在页面提示。

课表的周次标题使用主题强调色并加粗，配合实色背景保证壁纸上的可读性；周次选择框中选中项使用强调色背景与对应文字色。颜色跟随深浅色和主题预设。

## 数据与联动

- 按学期保存在现有 Room `kv_cache` 的 `whpu-periods:<semesterId>` 键中，数据库版本不变；没有设置时沿用原 WHPU 默认作息。演示作息独立保留。
- 重新导入课表和切换账号不会覆盖用户作息，行为与第一周日期等用户设置一致。恢复默认只影响对应学期。
- Repository 读取学校学期的课程和自定义日程时，将节次映射到当前作息。课表时间栏、课程详情、今日安排、小组件与上课免打扰因此使用同一组时间。课表返回时重读时间和课程，不需要重新登录或同步学校。
- 保存后刷新桌面小组件并重算已启用的免打扰计划；免打扰原有的缓存变更监听也会响应作息保存。
- 考试使用学校提供的独立时段，修改作息不会改动考试缓存或考试时间。

## 验证

- 493 项单元测试通过，失败、错误、跳过均为 0。新增 9 项覆盖节数、非法时钟、逆序、重叠、衔接、可变时长、课程数据映射以及小组件和免打扰的开始时间一致性。
- 64 项教务缓存设备回归通过，失败、错误、跳过均为 0。新增 6 项覆盖数据库重开、跨学期与演示隔离、重新导入、换账号保留用户设置、非法保存与写入失败保留、恢复默认及考试时间保护。
- Debug 与测试 APK 构建成功；OPD2407 / Android 16 覆盖安装保留原数据。
- 平板实测时分滚轮；临时将第 1 节开始时间从 08:00 改为 08:01，保存后课表立即更新，重新进入编辑页仍显示新时间。验收后恢复 08:00，并确认课表恢复。
- 目视检查浅色和深色周次标题、深色周次选择框的选中项，文字与背景可区分。结束后恢复原“跟随系统”主题，验收截图不入库并已清理。

本轮验证作息映射和计划计算，真实上下课的系统后台触发仍按[免打扰记录](whpu-class-dnd.md)继续验收。已发布的 rc2 安装包不包含本切片。
