# rc5 发布验收（准备中）

版本 `0.34.0-rc5`，`versionCode=104`。基线为 PR #17 合并后的 main `a759a74`，本切片增加校园卡小组件更新时间与窄宽度排版修复；保持 Room v10 与原工具链。

## 已有校园卡证据

PR #17 已在 OPD2407 / Android 16 验证真实网页登录交接、原生完整同步和手动刷新，余额及流水总数与官方页面一致。该切片 542 项单元测试和 20 项设备回归通过，见 [校园卡记录](whpu-campus-card-evidence.md)。这些是基线的验证记录，不计为 rc5 重新运行。

API 31 专用模拟器实际放置余额组件，读到人工所选卡余额和消费；点击进入原生校园卡页，切换卡片后组件更新。实体平板校园卡小组件尚待实放，已有课表小组件的用户验收不替代校园卡组件。

## rc5 本轮验证

- 543 项单元测试通过，失败、错误、跳过均为 0。
- Debug、测试 APK 和 R8 正式 Release 构建通过。签名与已发布 rc4 相同，版本代码 104、名称 0.34.0-rc5，未启用 debuggable。
- API 31 模拟器实际小组件布局修复通过：仅有校园卡时显示缓存更新时间，今日支出与笔数单独一行；浅色与刷新后的深色截图可读。组件点击进入原生页、切卡后更新已验证。
- 专用模拟器正式签名 rc4 → rc5 使用 install -r 覆盖升级。升级前后全部数据库表记录和 DataStore 字节完全一致；非空学习记录与标签保留，累计 25 分钟可见；原生校园卡人工缓存可在 R8 包中读取。
- 夹具使用此前保留的 rc4 人工数据，补入人工校园卡分区；没有复制真实平板账户数据。测试前从 Debug 切换正式签名时先备份，仅卸载专用模拟器中的测试应用。首次 root 恢复的文件归属/SELinux 标签不正确导致旧版 rc4 启动失败，修正夹具标签、确认旧版正常后才开始覆盖升级；系统安全策略保持启用。
- 本轮未重复运行 PR #17 的 20 项设备测试，不将基线结果计作新执行；版本与布局变更由 543 项单元测试、实际组件检查和正式升级覆盖。

## 发布与边界

本分支为发布准备，尚未发布候选版。最终包须在合并后基于 main 重建并核对源码提交、签名、版本与发布附件。

真实换账号、多卡、未绑定、自然失效后的完整重登录、实体设备断网重启/横屏仍待现场条件。校园卡认证仅驻留内存，冷启动可读缓存，再次刷新需通过学校网页交接。电费三组在北京时间上午仍返回 404，用户也确认失败；暂停原生化，不猜测恢复时间。图书借阅需要用户独立登录及验证码，座位预约、续借及支付均不自动提交。
