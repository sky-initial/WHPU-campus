# rc8 候选版准备与验收

版本 `0.34.0-rc8`，`versionCode=107`。基线为 PR #25 合入后的 main `7211b19`；沿用正式签名、Room v10 与现有工具链。当前是发布准备，未创建标签或 Release，最终包须在准备 PR 合并后从主线重新构建。

## 本版内容

“其他楼栋”分组支持学校网页登录后逐级选择房间、手动查询人民币余额及离线缓存。照明与空调分别选择，账号与房间分区保存；失败保留原余额和时间。今日页与“电费与校园卡”组件读取当前所选房间的金额，不显示电量或推算剩余天数。

其他两个分组继续使用官方网页。缴费与绑定留在学校页面由用户操作，未恢复后台采样。图书借阅登录、真实换账号/自然失效和 Reno 11 Pro 免打扰现场验收仍有外部依赖。

## 已有功能验证

功能切片 574 项单元测试、40 项设备回归通过；OPD2407 上授权房间的照明/空调查询、空调金额与官方只读响应对照、今日页、所选缓存与组件联动及断网冷启动通过。两倍字体下浅深色、横竖屏金额区域检查通过，设备设置恢复。详情见[原生电费记录](whpu-electricity-native.md)。这些是功能切片结果，不替代准备包及最终主线验收。

在版本递增前，另对功能分支 `718801c` 执行 Release/R8 编译与正式签名预检查：构建通过，签名与已发布 rc7 一致。专用 API 31 人工数据模拟器可读取电费金额缓存及冷启动缓存，校园卡和学习统计可读，数据库全部表与设置一致。该包仍为旧版本号，仅作未发布预检查；验证后恢复正式 rc7 和原人工数据并暂停模拟器。
