# rc8 候选版发布与验收

版本 `0.34.0-rc8`，`versionCode=107`。最终发布基线为 PR #26 合入后的 main `c0fc922`，沿用正式签名、Room v10 与现有工具链。[rc8 已发布](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc8)。

## 本版内容

“其他楼栋”分组支持学校网页登录后逐级选择房间、手动查询人民币余额及离线缓存。照明与空调分别选择，账号与房间分区保存；失败保留原余额和时间。今日页与“电费与校园卡”组件读取当前所选房间的金额，不显示电量或推算剩余天数。

其他两个分组继续使用官方网页。缴费与绑定留在学校页面由用户操作，未恢复后台采样。图书借阅登录、真实换账号/自然失效和 Reno 11 Pro 免打扰现场验收仍有外部依赖。

## 发布后配置切换排查

在已发布的正式 rc8、API 31 专用模拟器和人工数据上，分别检查校园卡与原生电费页面。单独切换字号、深色模式、密度和尺寸，以及组合切换后的样本，金额在无障碍节点范围内可见，主题符合预期。

额外按“组合修改配置 → 再打开电费页 → 切换浅色”顺序检查：早期样本中金额仍可见，但背景仍为深色；再等待 3 秒采集的样本已自行恢复浅色，无需冷启动。本轮没有复现持续的画面与节点坐标错位，也不能证明首次异常已经修复或确定其根因，未为此修改应用代码。

检查结束后，人工数据库全部表记录、显示设置和系统免打扰均恢复；模拟器已暂停。实体平板和学校登录页面未参与本轮检查。以上补查不计作单元测试或仪器测试数量，也不改变已发布产物。
