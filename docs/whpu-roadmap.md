# WHPU Pocket 后续任务

本计划依据截至 2026-11-08 的开发与验收结果，按功能依赖排序，不预设学校尚未核验的接口。每个功能切片单独测试、真机验收并提交中文 PR。

## 当前基础

- 学校页面交互登录、真实课表导入、第一周日期滚轮设置、离线课表与今日页已完成；用户确认小组件显示及点击跳转正常。
- 成绩查询切片已实现按学期完整分页、离线缓存，以及学校返回的成绩、学分、绩点、学分绩点展示；真实保存和断网冷启动已验证。
- 课表和成绩共享账号归属，支持首次升级保留绑定、换账号确认和事务清理。自动化回归为 435 项单元测试、37 项 Room 真机测试。
- 本轮真实成绩验收为单页 15 条；多页、跨账号和失败路径以人工数据回归。真实双账号切换、自然会话过期、验证码/MFA 仍待合适条件下实测。

## 1. 考试安排：下一个功能切片

**证据准备**：学校菜单已出现“考试信息查询”，但尚未核对其查询请求及响应。先确认入口、学期参数、分页、考试日期、起止时间、地点、座位号、考试性质，以及空安排或取消状态的实际表示。

**实现范围**：复用学校 WebView、请求取消和共享账号归属；新增按学期的考试列表、手动刷新和离线缓存。缺失或待定字段按学校状态展示，不生成推测日期、地点或座位。

**验收标准**：与学校页面核对记录；空结果、分页失败和换账号不串数据；断网冷启动仍可查看。学校当期暂无考试时，明确区分真实空结果与人工测试数据，待有安排后补充真实字段验收。

考试列表稳定、日期及时区含义核验后，再通过独立小切片接入今日页和小组件；通知提醒另行确认产品需求，不随列表功能自动启用。

## 2. 学期选择与日常使用完善

- 课表、成绩、考试统一学期名称与选择体验，记住最近选择，减少反复输入年份；各业务可查看不同学期，不因查询成绩自动切换当前课表。
- 增加可调整的上课作息入口，保留现有用户设置第一周日期的方式；核对学校作息或季节变化的可靠来源。
- 检查手机和平板布局、系统大字体及深浅色可读性；集中处理实际使用发现的问题。

**验收标准**：重启后恢复选择；切换学期不混用数据；更改作息与教学周后课表、今日页和小组件一致。

## 3. 测试版发布准备

- 完成首次安装、旧版本覆盖升级、仅演示数据、真实缓存迁移、无网和登录失效的整体验收。
- 明确数据来源、清除登录态与删除缓存的区别，以及本地数据的处理方式；保持 MIT 许可证与原版权声明。
- 采用独立的正式签名配置并明确更新兼容策略。当前缺少 release 签名配置时构建会使用 debug 签名，不能据此宣称已具备正式发行签名。
- 准备版本说明、已知限制和反馈方式。APK 发布与分发在产物及说明可审阅后再执行。

**验收标准**：可重复构建、覆盖升级保留数据、签名策略明确，发布内容与实际验证范围一致。

## 4. 后续校园服务

| 顺序 | 功能 | 接入前需确认 |
| --- | --- | --- |
| 1 | 空教室 | 学校查询入口、校区楼栋和教室标识、查询时间范围及占用规则 |
| 2 | 校园卡、电费 | 各服务允许的认证方式、账号或宿舍关联、余额与流水/电量字段 |
| 3 | 图书馆 | 实际可用入口、身份交接及可提供的查询服务；预约等写入操作单独设计 |

以上业务分别取得证据后逐项接入，不假定它们沿用教务会话，也不直接复用原郑大协议地址。

## 绩点统计的边界

当前逐门展示学校返回的 `jd` 和 `xfjd`。总 GPA、均分、排名及学分汇总需要先核对学校计算规则，尤其是补考/重修、作废成绩、等级制和不计入课程的处理；在规则与数据完整性明确前不自行计算。
