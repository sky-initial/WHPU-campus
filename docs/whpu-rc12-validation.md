# rc12 候选版发布与验收

版本 `0.34.0-rc12`，`versionCode=111`，沿用正式签名与 Room v10。功能 PR #37 已合并至 main `4fb178f`；本记录先登记发布准备，最终签名产物、升级与附件验证完成后补充结果。

## 变更

- 接通“常青 1 号楼、金湖 10、11 栋”的原生电费查询，按公寓、楼层、房间选择。三个分组均可读取所选房间缓存并在今日页与小组件显示。
- 根据用户于 2026-11-16 确认的人民币单位显示余额，保留查询数值的完整小数精度。官方返回字段仍名为“当前剩余电量”且未标单位，单位依据是用户确认，不从字段名或缴费金额推算电量。
- 兼容已有整数分、字符串元和第三分组开发版的未定单位缓存；读取旧缓存时保留数值、归属、房间及更新时间。
- 保留手动刷新、失败保留缓存、账号与项目隔离；缴费继续在官方页面由用户完成，小组件只读缓存。

## 功能提交验证

PR #37 的 `dcf736f` 已实际通过 589 项单元测试及 25 项设备回归（缓存 18、原生界面 3、小组件 4），Debug 与测试 APK 构建成功。设备回归使用专用 API 31 模拟器及人工数据，覆盖旧格式兼容、精度、刷新失败、重新打开页面、不同尺寸和深浅色。

实体平板覆盖 Debug 后，数据库及 DataStore 保留；原生页、今日页和桌面组件显示同一金额与房间，断网冷启动及组件点击回归通过，网络和系统免打扰状态恢复。正式 rc11 没有第三分组的未定单位缓存，该格式兼容属于开发版升级测试，不作为正式 rc11 的历史数据。

以上是功能提交的验证，尚不代表最终 rc12 签名包已完成验收。

## 最终发布门槛

- 从已合并、干净 main 构建，执行完整单元测试、Release/R8 与 lintRelease。
- 核对版本 111、正式签名、minSdk 31、targetSdk 36、非 debuggable 和 APK 源码提交。
- 专用模拟器离线完成正式 rc11 → rc12 覆盖升级，核对人工业务数据库、DataStore 和精确金额显示；恢复原包、数据、网络与免打扰状态并暂停模拟器。
- 归档最终 APK、mapping 和中文说明，发布候选版本，下载附件与本地被测产物逐字节比较并核对标签提交。

借阅认证、真实换账号和自然会话失效等仍需对应条件；本次发布不以重试教务来判断学校服务是否恢复。
