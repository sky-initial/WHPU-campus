## 正式签名覆盖升级

使用现有专用 Android 12 / API 31 模拟器 `WHPU_rc3_API31`，只使用人工数据，不复制实体平板个人数据。

1. 对 rc3 的课程、实践、自定义日程、成绩、考试及偏好建立快照，正式签名 rc4 使用 `adb install -r` 覆盖安装。
2. 关闭模拟器 Wi-Fi 与移动数据，确认人工课程、自定义日程可读。显式选择人工缓存所在的 2026—2027 第一学期后，成绩、绩点、学分绩点和考试可读；初始显示另一学期不等于缓存丢失。
3. 比较升级前后全部数据库表记录与 DataStore 文件，完全一致。
4. 为补齐非空学习记录覆盖，在专用模拟器恢复 rc3，从完整数据库快照准备一条已完成的人工 25 分钟专注记录及标签；旧版统计先显示 25 分钟。
5. 再次正式签名覆盖升级 rc4，学习统计仍显示 25 分钟。全部数据库表记录和偏好文件再次完全一致，包含非空 focus_sessions 和 focus_tags。

以上证明该人工数据集的覆盖升级与离线读取，不替代真实换账号、学校自然会话失效或进程回收验收。
