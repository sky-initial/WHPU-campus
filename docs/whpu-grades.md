# WHPU 成绩查询

## 已取得的接口证据

2026-11-08，用户从学校成绩页的网络面板提供请求方法、URL、表单参数和一段响应。原始响应含个人字段，未保存到工程或测试资源。浏览器页面已确认学期选项为第一学期 `3`、第二学期 `12`，并提供每页 15 条等分页选项。

```text
POST https://jwglxt.whpu.edu.cn/cjcx/cjcx_cxXsgrcj.html?doType=query&gnmkdm=N305005
Content-Type: application/x-www-form-urlencoded;charset=UTF-8

xnm=<学年起始年>&xqm=<3或12>&sfzgcj=&kcbj=&pkey=&_search=false
&nd=<当前毫秒时间>&queryModel.showCount=15&queryModel.currentPage=<页码>
&queryModel.sortName=+&queryModel.sortOrder=asc&time=2
```

`queryModel.sortName` 解码后是一个空格。`sfzgcj`、`kcbj`、`pkey` 保持用户实际请求中的空值，不启用只取最高成绩或限定课程标记的额外过滤。

| 字段 | 本切片处理 |
| --- | --- |
| `items` | 成绩记录列表 |
| `currentPage` | 当前页，必须与请求页码一致 |
| `totalPage`、`totalResult` | 用于完整分页校验；设备真实查询已通过解析并进入归属确认，确认这两个顶层字段可用 |
| `kcmc`、`kch` | 课程名称、代码 |
| `cj` | 保留原始文本，支持数值或等级；空值显示未公布 |
| `xf` | 学分文本，不做汇总或绩点计算 |
| `jd`、`xfjd` | 按用户补充要求展示学校返回的绩点、学分绩点，保留原始精度；不自行计算 |
| `kcxzmc` | 课程性质 |
| `ksxz` | 成绩性质，包含用户样本中的补考类型；同课程的不同记录分别保留 |
| `cjbz`、`cjsfzf`、`khfsmc` | 备注、作废标记、考核方式；备注列已在学校页面观察到 |
| `xnm`、`xqm` | 每条记录必须属于所选学期 |
| `xh` | 仅在内存中与同一学校会话的身份响应核对，不进入成绩缓存 |
| `xh_id`、`key`、姓名和其他学生信息 | 不持久化、不输出到日志、不作为课程标识 |

## 业务与缓存

- 入口为“更多 → 成绩查询”，按学期查看、手动刷新并展示本机缓存更新时间。登录入口复用已有学校 WebView；成绩查询不要求填写课表第一周日期。
- CookieManager 分别读取课表端点和成绩端点的适用 Cookie，放入 `/kbcx` 和 `/cjcx` 两个独立作用域，不扩展到 CAS 或其他教务路径。
- 每次查询使用固定的内存 Cookie 快照。先请求已验证的课表端点，只解析 `xsxx.XH_ID` 和 `xsxx.XH`，用于统一账号归属及逐条成绩核对；不导入或切换课表。即使成绩列表为空，也能先确定账号归属。
- 顺序读取全部成绩页，校验页码、总页数、总条数、每条记录的账号和学期。任何一页失败、分页信息变化或数量不完整时，保留旧缓存。缺失分页字段不当作有效空结果。
- 成绩缓存复用 Room `kv_cache`，每学期一个完整快照，只保存页面所需字段，未增加表或更改数据库版本。
- 课表和成绩共享 `whpu-cache-owner`。同账号刷新保留其他学期；换账号经确认后，在同一事务中清理旧学校课表、所有成绩快照和课程显示修改，再保存本次查询结果。自定义日程、演示课表和学期日期设置保留。
- 旧版未绑定账号的学校课表需要首次归属确认。用户确认“属于当前账号，保留并绑定”后，不清空已有课表或显示修改，绑定归属并保存本次查询结果。确认只对提示时的账号有效，重新请求若返回其他账号会再次提示；该选项不能覆盖已经绑定的不同账号。若用户明确选择其他账号替换，才执行跨学期清理。仅有演示缓存不触发此确认。
- 取消刷新、退出页面、会话变化和请求失败不会先清空缓存。清除网页登录态保留离线数据。
- 不计算 GPA、排名、均分或学分汇总，也不以分数推断补考、重修是否通过；每门课程的绩点和学分绩点直接展示学校字段。已有成绩快照缺少这两个字段时仍可读取，刷新后补齐。
