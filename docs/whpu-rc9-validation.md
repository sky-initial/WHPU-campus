# rc9 候选版准备与验收

版本 `0.34.0-rc9`，`versionCode=108`，沿用正式签名与 Room v10。[候选版已发布](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc9)，最终源码为 PR #30 合并后的主线 `7b808e1`。下文区分功能、准备包与最终产物验证。

## 内容与已有验证

学校登录页加载失败提示在操作区折叠时仍可见，提供保留登录态与缓存的重试；失败页面不启用同步，业务返回保持可用。人工 WebView 回归覆盖主文档 HTTP 503、响应流读取失败、子资源 503，以及成功重试后的状态恢复。

功能代码已实际运行 574 项单元测试和 3 项 API 31 设备测试，全部通过。相关错误回调顺序和首次失败记录见[登录错误提示](whpu-login-errors.md)。版本准备与最终发布验证另行记录，不将此前测试当作新产物验证。

用户确认 Reno 11 Pro 更新安装包后原免打扰退出问题解决；未据此推断具体根因。实体平板原 Debug 的校园卡四种显示配置补验见[校园卡证据](whpu-campus-card-evidence.md)，不是 rc9 产物验收。

## 发布门槛

准备包须通过正式签名/R8 构建和 rc8 人工数据覆盖升级检查。PR 合并后，最终主线构建还须核验源码提交、版本代码与签名，发布附件下载回验后再标为已发布。不得用卸载真实设备来完成换签名验证。

## 准备包验证结果

- 准备提交 `8b42864` 的 Release/R8 与发布 lint 构建通过；版本代码 108、名称 0.34.0-rc9，非 debuggable，正式证书与已发布 rc8 一致，APK 的源码元数据对应该提交。
- PR #29 合入主线 `adb022a` 后，将版本准备提交移到发布分支，得到 `b89732d`；两者完整源码树比较一致。后续仅追加本验证记录，最终主线产物仍需另行构建核验。
- 专用 API 31 模拟器在正式 rc8 上装入既有人工夹具，包含课程、自定义日程、成绩、考试、学习记录、校园卡与电费缓存；先核对旧版可读，再覆盖安装准备包。测试期间确认无默认网络，不访问学校。
- 升级前后所有 SQLite 表记录及 DataStore 字节一致。原生校园卡、电费余额及学习统计可读，电费冷启动缓存可读；系统免打扰保持原状态。此检查不替代真实账号或网页登录验收。
- 测试结束降回已发布 rc8，并原样恢复本轮开始时的模拟器数据库和偏好。恢复后不再启动应用，避免初始化改变原空库；原始文件逐字节及数据库表比较通过。网络设置恢复，模拟器暂停，实体平板未参与正式签名覆盖。

功能代码的 574 项单元测试及 3 项离线 WebView 设备测试见上节。本轮版本准备没有将它们记为重跑结果。

教务当前普遍无法进入，原因未知；本轮不访问教务，不把真实重登录、换账号或自然会话失效记为通过。其他电费分组和借阅仍受对应接口证据及认证条件限制。
