# rc10 候选版准备与验收

版本 `0.34.0-rc10`，`versionCode=109`，沿用正式签名与 Room v10。当前是基于 PR #32 的准备分支，**尚未发布**；只有相关 PR 合并后才从主线构建最终产物。

## 变更与功能验证

新增金银湖 6、7、8 栋照明原生查询，并保留真实余额的四位小数。原生电费页、今日页及小组件显示同一精确金额；旧版整数分缓存兼容读取，保留账号、房间选择及时间。

PR #32 功能代码已通过 582 项单元测试、20 项设备回归和 OPD2407 实际原生/官方金额对照、今日页、组件及断网进程重建检查，详见[原生电费记录](whpu-electricity-native.md)。这些是功能版本结果，不代替本次签名产物升级验收。

本次增加完整 `lintRelease` 检查。番茄钟通知更新显式处理通知授权撤销；课表背景的两个 `produceState` 已直接赋值，固定工具链仍报告未赋值，仅对这两个函数标注该项误报，不关闭其他检查。rc9 原记录已明确其通过的是构建附带的 `lintVitalRelease`。

## 发布门槛

- 使用正式证书构建 Release/R8，版本代码递增，检查 APK 的源码元数据、非 debuggable 及 SDK 配置。
- 从已发布 rc9 覆盖安装准备包，确认既有人工课表、日程、成绩、考试、学习记录、校园卡、电费及设置保留；旧电费缓存由正式包成功读取。
- 独立验证正式包对新精确金额载荷的读取、显示及持久化，不把向人工库加入新夹具算作旧版本升级保留。
- 测试后恢复专用模拟器原安装包、原数据库、偏好及网络/免打扰状态；实体平板不参与正式签名切换。
- PR 合并后，从干净的 main 重新构建和核验，发布后下载附件对照，完成后才标为已发布。

## 外部边界

第三个电费分组的官方查询已成功，但返回标为“当前剩余电量”的数值没有明确单位，继续保留官方网页。借阅缺少可用认证条件，教务当前不可用原因未核验；本次不重试这些服务。真实空结果、换账号及自然会话失效仍保留待验收。
