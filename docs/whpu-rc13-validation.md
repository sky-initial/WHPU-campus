# rc13 候选版发布与验收

版本 `0.34.0-rc13`，`versionCode=112`，沿用正式签名与 Room v10。PR #40 / #42 已合并，[候选版已发布](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc13)，最终包来自干净 main `d275f5c0b10c4059dba957acbb2a0b690c4169dc`。

## 变更

手机横屏且系统字体为两倍时，电费查询分组弹窗的第三个按钮原先会被压缩。分组选项现在可纵向滚动，按钮保留完整高度，关闭按钮位于固定操作区。学校请求、认证、金额精度与缓存逻辑保持现有实现。

## 功能提交验证

功能提交 `324f1bc` 已执行 589 项单元测试、5 项设备测试（新增两项深浅色大字体回归、原有三项原生查询流程），Debug 与测试 APK 构建通过。两项新增用例在修复前均因第三组裁切失败，修复后通过。

同一 Debug APK 在 API 31 模拟器完成手机/平板尺寸、横竖屏和深浅色的 8 组离线显示检查，均为两倍系统字体。人工金额、尾零和房间文字可完整查看；手机横屏第三组可滚动显示，关闭按钮可操作。各配置设置后重新启动应用，不将其视为连续旋转或实体设备验收。详情见[电费开发记录](whpu-electricity-native.md)。

## 最终签名包验证（2026-11-16）

从上述 main 实际重新执行 **589 项单元测试**，失败、错误、跳过均为 0。Release/R8 与完整 lintRelease 通过，lint 为 0 错误、144 警告、7 信息项，本次重新分析。APK 版本、应用 ID、最低及目标 SDK、非 debuggable、源码元数据均核对通过，证书与正式 rc12 一致。

专用 API 31 模拟器在无默认网络下安装正式 rc12，装入此前由 rc12 写出的三组人民币人工缓存，并在旧版中依次选择三个房间。覆盖安装最终 rc13 后，全部数据库表记录与 DataStore 字节一致，涵盖课表、日程、成绩、考试、学习记录、校园卡与电费；校园卡、今日页、学习统计及所选第三组余额在原生页和冷启动后可读。三组金额缓存保留原精度，所选第三组的 `48.1200` 保留尾零。

最终签名包另完成 1920×1080 / 420 dpi、两倍系统字体下的深浅色弹窗检查：第三组可滚动至完整显示，关闭按钮可操作；截图复核确认所选金额和房间文字完整。显示检查前后所有表记录与 DataStore 仍相同。该结果来自人工数据模拟器，不替代实体设备或真实认证状态验收。

结束后恢复原正式 rc8、数据库和 DataStore 原始文件、网络、显示及免打扰状态，并暂停模拟器；实体平板和学校登录页面未操作。

已发布 APK 为 **6,043,084 字节**，mapping 为 **48,610,861 字节**。两项附件下载后与本地被测归档逐字节一致，远程标签指向上述源码提交。
