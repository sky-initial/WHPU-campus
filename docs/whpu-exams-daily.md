# 考试接入今日页与桌面小组件

日期：2026-11-09。基于已合并的 rc2 功能与考试缓存，复用现有 Repository、今日页、RemoteViews 小组件，不新增服务端请求或数据库版本。

## 显示规则

- 今日页新增考试卡片，读取**当前课表学期**的学校考试缓存，显示课程、起止时间、未开始/进行中/已结束状态、考场、考试校区及缓存更新时间。点击进入考试列表，首次进入默认选中当前课表学期；手动查询其他学期不切换课表。
- 未同步与已同步空结果分别显示“尚未同步”和“本地缓存中暂无今日考试”。有时间缺失或暂不支持的记录时，提示查看完整列表。
- 今明课表小组件将课程和考试按开始时间排序，同时开始时考试在前；考试名称加“考试 · ”前缀，考场与校区使用考试字段，行点击进入考试列表。下一节课小组件同样纳入考试，点击去向跟随当前主要内容。
- 已结束的考试退出小组件待办列表；明日考试参与预告；考试明确的起止时间参与现有小组件非精确刷新调度。数量文案在混排时使用“项”和“场”。
- 考试有独立的实际日期，显示不依赖第一周设置和教学周范围，假期提示不会盖住今明两日已有的考试。

## 时间与缓存

学校已核对的时间字段为 `kssj`，格式为 `yyyy-MM-dd(HH:mm-HH:mm)`，参见[接口记录](whpu-exams.md)。沿用项目北京时间 `Asia/Shanghai`，以开始时刻包含、结束时刻不包含的规则判定进行中。接受空白及中文括号；非法日期/时钟、缺少时段、结束早于或等于开始的记录不推测时间，原文完整保留。

今日页在可见期间按分钟更新，返回页面重新读取；缓存更新、当前学期变化和账号清理会触发重新读取。当前学期与考试缓存在 Room 事务中读取，小组件也在同一事务中读取课程和考试，避免把不同缓存状态拼在一起。演示学期不混入学校考试；离线使用现有缓存，不自动访问学校。Room 的变更流依据[官方 API 文档](https://developer.android.com/reference/kotlin/androidx/room/package-summary)，使用本项目 2.6.1 已支持的 `invalidationTrackerFlow`。

## 验证

- 484 项单元测试通过，失败、错误、跳过均为 0。新增 15 项覆盖日期/时段解析、北京时间跨日、考试开始结束边界、未知时间、课程考试混排、假期覆盖、考试点击目标及刷新边界。
- 23 项考试相关设备回归通过（21 项考试缓存、2 项 RemoteViews），包括新加的当前学期切换监听、数据库重开、演示隔离、空缓存与空结果区分、跨账号移除旧考试、深浅色行渲染和 PendingIntent 路由隔离。学期切换监听补充断言后单独复跑通过，不重复计数。
- Debug 应用与测试 APK 构建成功，OPD2407 / Android 16 覆盖安装保留数据。今日考试卡片、当前学期未同步提示、点击进入考试列表及当前学期默认选择已实测。
- 自动化数据为人工构造，设备测试使用独立临时数据库；没有将人工考试写入用户数据库，也没有改动用户设备日期。

实际考试当天的卡片内容、桌面考试条目点击及厂商后台刷新延迟仍待对应真实场景验收。此次不新增考试通知，也不将考试纳入上课免打扰；rc2 已发布包不包含本切片，后续版本发布时再更新安装包。
