## 实现

“更多”和今日页接入校园卡、电费及图书馆；图书馆拆分借阅和预约。校园卡和电费从门户选择“虚拟校园卡”，不猜测 SSO 请求。座位入口不携带临时认证参数、不固定预约日期。原教务跳转策略保持独立。

应用内网页按服务限制已核验的主页面跳转域名，遇到其他域名说明无法内嵌并提供外部浏览器入口；不绕过证书错误。外部浏览器始终打开正式入口，不转发内置网页当前 URL 或登录态。OPAC 保留外部浏览器模式，应用明文流量仍禁用。

门户使用普通浏览器的桌面 UA（保留系统 Chromium 版本），首个有效布局后开始加载。OPD2407 上观测到 CSS 视口为零，门户根节点高度随之为零；仅在该条件成立时按实际视口补根节点高度。通用 `vh` 修复每轮重算原始样式表、排除自己的补丁，并保存内联声明原值供旋转重算；正常视口不改写。通用结构性补高仅检查 body 直属容器，避免给内层零高度工具栏补高后挤走登录表单。

WebView 由导航条目 ViewModel 持有，仅在内存中跨旋转保留页面；退出页面销毁 WebView。MutableContextWrapper 在重新挂载时绑定当前 Activity，移出时释放 Activity 引用；导航、移出窗口和销毁均取消待执行的修复。网页历史及认证地址不写入 SavedState、偏好或日志。页面支持返回、返回入口、重试与外部浏览器；内置网页共用 Android Cookie 存储，登录页全局清理须先确认影响范围。

本切片不添加 Room 表、不缓存校园卡/电费/借阅数据、不改变桌面余额数据来源或恢复电费后台采样。旧网络客户端继续阻断。

## 学习通登录显示问题

OPD2407 实测 `/login` 的账号、密码框存在，但顶部 `.lg-top` 被旧结构性补高设为整屏高度，左侧表单被父容器裁掉；右侧二维码仍可见。修复收窄到最外层容器，不修改认证字段、显示策略或登录方式。修复版真机截图及用户确认：账号、密码与验证码登录入口已恢复可见。用户随后确认真实登录后可以进入校区／阅览室列表。预约提交、取消与签到没有代用户执行。
