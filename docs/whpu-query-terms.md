# 成绩与考试学期记忆

## 行为

- 从「更多 → 成绩查询 / 考试安排」打开时，分别恢复最近一次手动选择的学年与学期；选择后即保存，不要求先联网刷新。
- 未保存过选择时，成绩沿用按北京时间推断的学期，考试优先使用当前学校课表学期；没有学校课表时再按日期推断。推断仅用作选择器初值，用户可以修改。
- 今日考试卡片与桌面小组件进入考试页时优先查看当前课表学期。自动定位不覆盖最近一次手动查询选择；在页面主动切换学期则保存新选择。
- 切换成绩或考试学期不改变课表当前学期，不发起网络请求、不删除任何缓存。
- 打开学校登录页再返回、屏幕旋转时保留当前页面的选择。加载完成前禁用查询；保存失败时保留原选择并显示重试提示。

## 实现

复用 `ui_prefs` DataStore，以 `whpu_query_term_grades` 与 `whpu_query_term_exams` 两个键保存学校学期 ID；不改 Room schema。偏好只含学期，不包含账号信息。ViewModel 管理初次恢复与写入状态，持久化成功后再切换显示，配置变化时复用页面状态。

普通考试路由保持 `exams`，今日入口使用 `current_exams`。已有桌面组件的 `exams` Intent 在接收时映射到当前学期入口，保证升级后的旧组件仍能定位当天考试。
