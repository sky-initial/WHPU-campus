# WHPU 考试安排

## 接口证据

2026-11-08，学校“考试信息查询”页面与用户提供的网络面板记录确认了以下接口。用户提供的原始响应含个人信息，未保存到工程；测试全部使用人工数据。

```text
POST https://jwglxt.whpu.edu.cn/kwgl/kscx_cxXsksxxIndex.html?doType=query&gnmkdm=N358105
Content-Type: application/x-www-form-urlencoded;charset=UTF-8

xnm=<学年起始年>&xqm=<3或12>&ksmcdmb_id=&kch=&kc=&ksrq=&kkbm_id=&_search=false
&nd=<当前毫秒时间>&queryModel.showCount=15&queryModel.currentPage=<页码>
&queryModel.sortName=+&queryModel.sortOrder=asc&time=1
```

`queryModel.sortName` 解码为一个空格。学校页面确认第一学期 `3`、第二学期 `12`；用户提供的 2025 学年第一学期样本为 `currentPage=1`、`totalPage=1`、`totalResult=4`。分页使用这三个顶层字段，行内小写 `totalresult` 不代替顶层分页。

| 学校字段 | 用途 |
| --- | --- |
| `items` | 考试记录，保留学校顺序；同课程多场考试分别展示 |
| `kcmc`、`kch` | 课程名称、课程代码 |
| `kssj` | 考试时间原文；已见格式为 `日期(开始时间-结束时间)` |
| `cdmc`、`cdxqmc` | 考场、考试校区 |
| `ksmc`、`ksfs` | 考试名称、考试方式 |
| `cxbj` | 学校“重修标记”列；非“否”时显示原文 |
| `ksbz`、`khfs` | 学校页面列定义确认备注、考核方式，用户样本未包含值；有值时展示 |
| `xnm`、`xqm`、`xh` | 内存中核对所选学期和同一会话身份，不写入考试记录缓存 |
| `sksj`、`jxdd`、`xqmc` | 上课信息，不用作考试时间、考场或考试校区 |

未确认座位号字段，也未确认取消考试专用状态；不从 `zxbj` 等字段猜测含义。时间、地点为空时显示“未公布”，待定等文本保留原文。暂不解析成日期、不接入今日页、小组件或通知提醒。

## 查询与缓存

- 入口“更多 → 考试安排”，选择学期后手动刷新，展示缓存条数及北京时间的缓存更新时间。
- 复用学校 WebView 登录；登录返回考试页，查询不要求设置课表第一周日期，也不切换当前课表。
- CookieManager 分别读取课表、成绩、考试端点的适用 Cookie，内存中分别限定在 `/kbcx`、`/cjcx`、`/kwgl` 路径。
- 成绩与考试共用固定会话快照、课表端点身份核对和完整分页收集逻辑；空结果也先确认账号。所有页成功且条数相符后才保存。
- 每学期复用 Room `kv_cache` 保存完整考试快照（`whpu-exams:<year>:<code>`），只保存展示字段，不保存原始响应、学号、姓名或服务器标识。数据库版本不变。
- 课表、成绩、考试共用账号归属。确认换账号后，旧账号所有学期的三类学校数据和课程显示修改在同一事务中清理，再保存新结果；保留演示、自定义日程和日期设置。任何写入失败会回滚。
- 同账号查询只更新所选学期；取消、会话变化、网络失败、解析失败和后续页失败保留旧快照及更新时间。

## 验证

独立临时 Room 数据库用例覆盖关闭重开、跨学期保留、课表/成绩/考试双向账号清理、取消、会话变化、失败回滚、有效空结果和旧版未绑定课表的归属确认。

自动化结果：450 项单元测试、54 项 Room 真机测试全部通过，失败、错误、跳过均为 0；Debug 应用和测试 APK 构建成功。设备为 OPD2407 / Android 16，覆盖安装与标准设备测试均保留应用数据。

真实查询已验证：2025 学年第一学期保存 4 条考试安排，与用户提供的学校分页总数一致；未再次要求绑定已确认的账号。学校真实多页、双账号切换、自然会话过期及取消考试状态仍需对应条件验证。


最终设备验收：

- 确认系统无默认网络后强制停止并冷启动应用，重新选择相同学期，4 条缓存及可见考试时间、考场、校区与重启前一致。

界面调整：成绩查询与考试安排共用点选式学年选择器，显示完整学年名称；点击后从列表选择，第一/第二学期继续使用选择按钮，无需输入年份。

选择器验收：Debug 构建成功并覆盖安装；OPD2407 上两个页面均无可编辑输入框，点选 2025—2026 学年分别显示原有 15 条成绩、4 条考试。切到第二学期不混用第一学期缓存，切回后恢复对应记录，取消学年弹窗保留原选择。
