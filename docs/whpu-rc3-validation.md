日期：2026-11-13。版本：`0.34.0-rc3`，`versionCode=102`。沿用独立发布签名，Gradle、AGP、Kotlin 版本不变，Room 仍为版本 10。

## 本次内容

汇总已合并的考试今日页与小组件、自定义上课作息、本周高亮；修复验收中发现的窄屏大字体选周挤压和应用深浅色与系统栏图标不同步。README 改为当前 WHPU 功能与安装说明，保留原 MIT 许可证与版权声明。

系统栏继续使用现有 AndroidX Activity 依赖，通过 [SystemBarStyle](https://developer.android.com/reference/kotlin/androidx/activity/SystemBarStyle) 的深浅色判定回调匹配应用设置，不升级工具链。

## 正式签名安装与覆盖升级

使用独立 Android 12 / API 31 手机模拟器，不读取或复制平板个人数据。

1. 全新安装正式 rc3，无需登录显示演示课表；启用飞行模式、关闭 Wi-Fi 与移动数据后，强行停止并重新打开仍可读取演示。
2. 在同一专用模拟器重新安装已发布 rc2，使用人工数据准备学校来源课程、实践、自定义日程、成绩、考试和账号归属缓存。通过 rc2 界面保存第一周日期、实线描边和深色主题，确认课程、成绩绩点及考试可读。
3. 保存旧版数据库和 DataStore 快照，通过 `adb install -r` 覆盖安装正式 rc3。
4. 断网打开课表、成绩、考试及设置，检查第一周日期与本周标记；今日页能读取旧版考试缓存。比较升级前后数据库所有表记录与 DataStore 文件，结果一致。
5. 断网刷新成绩与考试时显示网络错误，已有缓存继续显示。正式版作息滚轮把第 1 节从 08:00 改为 08:01，保存后课表同步变化，冷启动后仍保留。

以上证明人工缓存的正式签名升级与离线读写；不替代真实双账号或学校自然会话过期验收。
