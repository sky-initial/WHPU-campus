# 下课免打扰退出排查

## 用户反馈与边界

用户在 OPPO Reno 11 Pro 上反馈：上课能进入免打扰，下课未自动结束，重新打开应用也不会立即结束。后续截图显示“等待下一次上课”，因此应用当时已判断不在上课时段；用户关闭应用功能开关后，系统免打扰仍开启。该手机当前未连接电脑，尚未读取系统正在生效的具体规则，不能据此认定用户手动开启过免打扰，也不能宣称已修复。

应用原本会在 Activity 恢复时重新计算课程并发送本应用规则的条件状态。本次补充预计结束／下一次开始的北京时间，便于核对课时判断；独立展示系统实际免打扰状态，监听系统状态广播，并在返回页面时重读。功能开关关闭但系统仍开启时提示查看生效来源，提供系统免打扰设置入口；不支持该入口的设备回退到声音设置。只操作本应用的自动规则，继续保留系统手动设置及其他规则。

## 回归增强

- 原系统测试在下课后删除规则，再检查全局模式；删除动作可能掩盖条件切换失败。现改为删除之前检查模式已恢复，并确认规则仍保留启用。
- 检查下课时保留另一个活动规则，而不只检查关闭开关的路径。
- 新增重建控制器后读取原规则并结束已过期课时的用例。
- 新增系统禁用规则后应用不重新启用的用例，以及功能关闭时其他临时规则激活／结束的界面状态回归。

## 已复现并修复的兼容性问题

API 31 上，系统规则已删除后，旧实现仍保留其 ID；随后关闭功能时先向该 ID 发送结束条件，系统 `ZenModeHelper.setAutomaticZenRuleStateLocked` 抛出空引用异常。设备测试实际复现了这条路径。现在发现规则已删除就清除过期 ID；关闭功能直接移除本应用规则，不再先更新一个可能已不存在的规则；已关闭配置中遗留的失效 ID 也在刷新时清理。新增用例覆盖删除后直接关闭、刷新后关闭、旧失效 ID，以及系统禁用后不重建。

这个缺陷已与 Reno 11 Pro 的反馈分开记录，后者尚未取得具体系统规则证据。

## 独立模拟器观察

使用 API 31 专用模拟器的正式 rc5，只有人工课程和缓存；先备份人工数据库，不复制实体设备数据。设置带明确日期和起止时刻的短人工课时，测试单位不映射学校作息，避免覆盖人工秒级边界。应用退到后台并熄屏后，实际系统闹钟触发免打扰；上课后通过 `am kill` 回收后台进程，确认进程已不存在。到下课边界，系统模式从优先免打扰恢复为关闭，没有打开应用或手动调用刷新。采样间隔约 5 秒，此结果不用于宣称精确延迟。

这验证了 API 31 正式包的后台进入、进程回收后下课退出路径，不替代 Reno 11 Pro 的故障现场。根据手机已显示不在上课时段、关闭功能后系统仍开启的反馈，继续检查系统规则状态和其他免打扰来源。

另外一轮将模拟器因暂停产生的时钟偏差校正后，在人工上课时段重启模拟器：开机后未打开应用，课程仍处于免打扰状态，下课边界自动恢复关闭。测试完成后恢复人工数据。重启使 adbd 回到普通权限，第一次还原人工数据库因此失败；恢复专用调试模拟器的 adbd root 后还原成功，未修改实体设备权限。

权限撤销用例：在另一段人工上课时段撤销精确闹钟权限。系统记录明确显示精确闹钟因权限撤销被移除，备用非精确闹钟仍在待执行队列。备用闹钟的申请时间为下课后 60 秒，系统另给约 154 秒批处理窗口；首次观察截止时该闹钟仍在队列中，因此延长对同一闹钟的观察，没有重开应用或重排调度。最终在下课后约 217 秒采样到免打扰关闭。该结果证明此条件下备用清理生效，不承诺权限撤销后准点退出；用户手机截图中两项权限均已授予，不能把本用例当作其故障原因。测试后恢复人工数据库及原权限并暂停模拟器。

## 本轮执行结果

- 19 项 `ClassDndPlannerTest` 单元测试通过，失败、错误、跳过均为 0；Debug 与测试 APK 构建成功。本轮只运行免打扰相关单元测试，不把先前 543 项全量结果计为重跑。
- API 31 模拟器的 7 项 `ClassDndSystemTest` 和 1 项 `ClassDndStatusScreenTest` 通过；OPD2407 / Android 16 覆盖安装保留数据，同样 7 项规则测试和 1 项界面测试通过。临时规则清理后，两端系统免打扰均为关闭，与测试前一致。
- 界面初次检查未通过：平板当时仍在锁屏，模拟器的初版文字查询也没有取得页面上的 Compose 文本。改为遍历可访问性节点核对原文字断言，平板由用户授权正常解锁后重跑，两端通过。平板临时亮屏设置已恢复原值。
- 模拟器为运行界面测试由正式签名切换为 Debug，先备份人工 Room 与 DataStore 数据。首次夹具误还原旧空加密偏好，引发密钥不匹配；移除该无实际凭据的人工副本后正常启动。没有卸载实体平板应用；这次测试环境换签名不属于正式版本的覆盖升级验收。
- 模拟器深色页面排版可读，实际点击系统免打扰入口并返回成功；系统规则变化时页面状态实时更新。
- API 31 的实际后台观察完成后关闭功能、恢复人工数据库及测试前权限，暂停模拟器。没有修改用户故障手机的数据或系统设置。
- 当前代码修复了已复现的规则清理兼容性问题，并改善课时和系统状态显示；手机上的退出问题保持待定位，没有强制关闭用户的全局免打扰。
