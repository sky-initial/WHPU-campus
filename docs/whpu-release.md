# WHPU Pocket 发布与安装

## v0.34.0-rc6

`versionCode=105`，沿用正式签名。[已发布候选版](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc6)，基于 PR #21 合入 main 的提交 `9c3e11d` 构建，包含 PR #19 / #20 的修复。

- 修复系统已删除上课免打扰规则时，关闭功能仍操作失效规则 ID 的兼容性异常。
- 免打扰页面分别显示课时计划和系统实际状态，提供预计结束/下次上课的北京时间及系统设置入口。下课与关闭功能只结束 WHPU 规则，保留系统定时、其他规则和手动设置。
- 余额组件停止读取旧电费缓存，显示待接入及官方网页入口；校园卡缓存时间统一使用北京时间。预览复用正式布局并标注示例数据。
- 电费用户已能在今日校园内进入查询页，WHPU 的可用分组和查询接口仍待核对；借阅仍需独立登录，座位预约由用户在官方页面完成。

最终主线重新执行 547 项单元测试，全部通过；正式签名 rc5 → rc6 覆盖升级保留人工数据库与 DataStore，发布后的 APK 与 mapping 下载回验逐字节一致。补充了 API 31 人工数据下的深浅色、两倍字体及手机/平板尺寸检查，范围见 [rc6 验收](whpu-rc6-validation.md)。

Reno 11 Pro 的“下课后系统仍免打扰”仍待取得该手机生效来源证据，不宣称本版已解决现场问题。

## v0.34.0-rc5

`versionCode=104`，沿用独立正式签名。[已发布候选版](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc5)，基于 PR #18 合入 main 的提交 `0d8b4ca` 构建。校园卡主线已通过 PR #17 合并，候选版增加余额小组件的显示修复。

- 校园卡在学校网页登录后手动同步余额与完整账单，支持离线缓存、账号/卡分区及多卡选择记忆。
- 今日页和余额小组件读取同一份所选卡缓存，失败不覆盖旧结果，小组件不联网查询。
- 修复仅有校园卡缓存时更新时间被“没设置房间”覆盖，以及窄尺寸下今日消费被金额挤掉的问题。
- rc5 发布时电费三个官方分组返回 404，保留入口和错误提示；后续可用情况见最新版本记录。借阅仍需独立登录，座位预约继续由用户在官方页面操作。

已核验 main 最终构建的源码提交与签名、正式签名 rc4 覆盖升级及发布附件。详情见 [rc5 验收](whpu-rc5-validation.md)。

## v0.34.0-rc4

`versionCode=103`，沿用独立发布签名。[已发布候选版](https://github.com/sky-initial/WHPU-campus/releases/tag/v0.34.0-rc4)，基于 PR #16 合入 main 的提交 `7576791` 构建，正式签名 rc3 覆盖升级验收通过。

- 接入校园卡、电费的融合门户入口，以及图书借阅与超星座位预约入口。
- 修复门户白屏、学习通账号密码区被裁剪、重复视口修复失效和旋转后布局恢复。
- 移除空教室入口；成绩和考试分别记忆学期；清除应用内网页登录态前明确影响范围。
- 网页支持返回、重试、外部浏览器。OPAC 使用外部浏览器，预约、签到、续借、充值由用户在官方页面完成。

本轮已有 507 项单元测试、6 项新增网页设备测试通过；座位预约真实登录后进入校区／阅览室列表已获用户确认。最终构建、签名及覆盖升级结果见 [rc4 发布验收](whpu-rc4-validation.md)。

校园卡、电费和借阅仍为官方网页入口，尚未实现原生余额、流水或借阅缓存。电费本次凌晨访问部分分组返回 404；用户反馈早上通常恢复，具体时段未确认。

## v0.34.0-rc3

`versionCode=102`，沿用 rc1 / rc2 的独立发布签名。

- 考试安排接入今日页和两个课表小组件，按时间混排，点击进入考试列表。
- 支持按学期设置第 1—11 节上、下课时间，课表、今日页、小组件与上课免打扰统一使用用户作息；考试时间独立保留。
- 实际本周使用强调色、加粗和“本周”标记；查看其它周时单独标注“查看”。选周网格根据宽度与字体自动换行，内容较多时可滚动。
- 修复应用主题与系统主题不同时，状态栏和导航栏图标对比度不正确的问题。

验证包括 493 项单元测试、66 项缓存与小组件设备测试，以及独立 Android 12 模拟器上的正式签名 rc2 → rc3 覆盖升级。数据库逐表记录及 DataStore 偏好文件均保留；模拟器采用人工课程、实践、日程、成绩与考试数据，不复制个人教务数据。OPD2407 / Android 16 继续使用开发签名覆盖安装，保留原数据。详细步骤和边界见 [rc3 发布验收](whpu-rc3-validation.md)。

## v0.34.0-rc1

首个 WHPU 测试发布，`versionCode=100`，应用 ID 为 `com.whpupocket.app`。最低 Android 12（API 31），目标 Android 16（API 36）。版本号延续工程原有序列，名称使用 `rc1` 标识测试版本。

包含学校页面登录、真实课表与实践安排导入、导入后设置第一周日期、离线课表、今日页与课表小组件，以及按学期查询的成绩和考试安排。成绩展示学校返回的学分、绩点和学分绩点；成绩和考试的学年、学期均使用点选控件。

## 安装及更新

- 从本仓库 GitHub Releases 下载 APK，在 Android 系统中授权所用浏览器或文件管理器安装。
- 本次 APK 使用独立发布签名。之后正式签名的版本沿用同一密钥，并递增 `versionCode`，以支持覆盖升级。
- 此前通过 ADB 安装的 debug 测试版与本次 APK 证书不同，不能直接覆盖安装。卸载会删除本地课表、成绩、考试、日程及设置；需要这些数据时请先保留旧版，当前没有提供一键迁移流程。
- Debug 构建继续使用原开发签名，配置发布密钥不会改变平板上测试版的后续调试升级方式。本次发布流程不卸载现有测试版。

## 签名维护

发布密钥和密码保存在仓库之外，由项目维护者备份；根目录 `keystore.properties` 已被 `.gitignore` 排除。不要把密钥、密码或该配置文件上传到 GitHub、PR、Release 附件。

本地配置字段：`storeFile`、`storePassword`、`keyAlias`、`keyPassword`。仅使用维护者持有的真实配置，不提交凭据示例值。发布任务需要有效签名配置，不再回退到 debug 签名。

```powershell
.\gradlew.bat --no-daemon :app:testDebugUnitTest :app:assembleRelease
```

发布前检查 APK 的签名有效、证书属于发布密钥，且应用 ID、版本代码、版本名称和最低 Android 版本正确；使用完整提交创建版本标签，使源码与 APK 对应。保留本地 R8 mapping 文件用于排查混淆后的崩溃，不必作为用户下载附件。
